解析器的作用

任何我们所写的代码在本质上就是 Text 文本，后缀无非是利于 IDE 或编辑器快速识别格式以便进行解析。我们的源码文件最近都将有编译器转换为字节码最终由 CPU 执行。但是编译器也并非直接处理 Text 文本，再者说，在编译以前我们也需要 IDE 能够提供语法高亮，语法检测，定义跳转等功能，每门编程语言都有自己的语法规则，而要进行语法校验就需要使用到语法解析器来将语法解析为抽象语法树(AST / Abstract Syntax Tree)。
