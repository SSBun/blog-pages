JavaScript, Learning

Recently, I’m learning React Native for developing a cross-platform live room component running in Android and iOS
applications. Even though I know some basic information about JS, it’s not enough to me to develope a complex React Native application.There is the place for recording complex features of JS and results of my thinking.

Basic

  • There are two global variables: window on web and globalThis for normal.
  • Declaration of variables declared with var will be lifted to scop top. Only declaration no implementation
  • const only prevents re-assignments,but does’t prevent mutations. you can still modify content of a const object or array.
  • JS has eight types:
    • Boolean: true or false.
    • nul: Not equal to Null or NULL.
    • undefined:
    • Number: int, float or double.
    • BigInt:
    • String:
    • Symbol: A data type whose instance are unique and immutable.
    • Object:
  • Using + between numbers or strings will always convert the number to string. Other operators -, * or / don’t do this conversion.
  • Extra commas in array are empty elements that you can treat them as placeholders. Index getter will return undefined.
  • String literals /my name ${person.name}/`` and tagged literals
  • Falsy values: false, undefined, null, 0, NaN and the empty string "".
  • JS switch case uses === as the matching method.
  • Exception handling
    • Using throw to throw errors of any types.
    • Using try ... catch to catch errors
    • The finally block always is invoked at end, its return value would be the final result of the whole try-catch block.
  • Function hoisting only works with function declarations, not with function expressions.
  • Nested functions with conflict names.
  • Getting function detail parameter information with the property arguments.
  • Arrow function doesn’t have its own this, arguments and super. It’s always anonymous.

Collections

Indexed collections

Array is the most used indexed collection type. Other likewise objects like argumentsof function isn’t real array type. There are some array functions the arguments can not invoke. For example: the forEach method.

But we can invoke the original method Array.prototype.forEach.call(arguments, (list) => { }) to be as a workaround.

Keyed collections

Map, WeakMap and Set are usual keyed collections in JS. the Map is similar to Object but has some differences. We can only invoke set, get and delete method to modify a map’s value. Normal dot method will modify the map’s property, treating it as an object.

Destructuring assignment

  • Binding array or object to variables.
  • Binding with more variables.
  • Object binding.
  • Object assignment.
  • Destructing with default values
    null is valid value not trigging default value assignment.

The default value evaluation is lazy, only be executed when conditions satisfy.

  • Rest property
    The rest property must be last property.
  • Swapping variables
  • Ignoring unused variables
  • Prototype chain
  • Binding pattern used in the reset property
    The rest property will be as an array object that can also be destructed by ...{}.

But this pattern can not be used in object binding.

TypeScript

Union Types

We can union several types into one with |.

Not only types can be united, literal values can also be union types (termed as literal type). that means we can define a type just receiving several special values.

As you can see above, the variable position referring to the string top is not a valid value of type Position. Since the variable can change its value, the TS compiler can not sure the position must be one of the four Position cases.
There is a workaround, using as to convert string variables to literal types.

Type Interface

Using type interface can declare a type that must contains some properties or methods.

The class Person implementing the interface Animal should have required properties and methods.

An interface can inherit another interface.

Interface types can be reopened to add new properties or methods.

Type Alias

Another way to quickly declare a type is using type alias.

We can not redeclare type with the same name for extending new definitions or extend it to inherit from other types.
But we can use & to merge multiple types.

Type Compatibility

When we assign an object to a typed variable, the instance must least has all properties of the type. Of course, the instance can have more properties, that won’t cause compilation errors.

Type Predicates

In TS, only base types can be checked by using if (typeof baseValue ==== 'string'). If wanting to check custom types, we can use the type predicate to do it.
