我喜欢的 Mac 软件

开发

Code Runner - 快速执行代码

  • 付费
  • 可以直接运行多种语言,可以自行添加语言支持
  • 代码高亮，代码提示
  • 支持断点调试
  • 在线查询文档

Woodpecker - iOS 项目调试

  • 付费
  • 查看和修改模拟器和真机中的沙盒文件,修改 UserDefault 文件
  • 网络抓包
  • UI 界面调试 (类似于 Reveal)
  • WebView 调试
  • IO 监听
  • 插件支持
  • 其他… (我不常用)

PPRows - 代码统计

  • 开源
  • 指定文件类型，忽略文件类型
  • 小巧，简单，快速

iCircuit - 电子电路模拟软件

不必多说

  • Visual Studio Code
  • Postman

系统工具

The Unarchiver - 解压神器

  • 免费
  • 支持超多种压缩格式
  • 双击解压，解压后可自动删除压缩文件 (清爽)

BitBar - Put anything in your Mac OS X menu bar

  • 开源
  • 支持多种语言 Ruby、Python2、Python3、JavaScript、CoffeeScript、Swift、Go、Lisp、Perl5、PHP
  • 现有大量的插件
  • 入手简单，快速定制自己的脚本

Moom - 窗口管理

  • 付费
  • 可以在窗口的放大选项上进行窗口调整
  • 绑定快捷键快速调整窗口大小
  • 灵活设置显示窗口的比例
  • 记录当前屏幕中的软件窗口的位置大小，下次可以一键恢复原
  • …

PicGo - 最强图床

  • 开源
  • 支持多种图床和云存储、七牛、腾讯云、又拍云、阿里云、Github、SM.MS、Imgur
  • 可以直接上传剪贴板内的图片
  • 图片重命令
  • 上传成功后，自动复制链接到剪贴板（链接有 5 种类型: Markdown、HTML、URL、UBB、Custom）

Numi - 美美的计算器

  • 免费
  • 简约、漂亮
  • 可以使用自然语言（Addition、Substraction、Exponent…）
  • 有注释、变量
  • 能进行货币、时间的换算，及高级的数学计算
  • 能编写插件实现你的特殊运算

自动切换输入法 - <<<

  • 免费
  • 简单
  • 根据软件自动切换输入法

我不喜欢使用 shift 键在一个输入法里面切换中英文，我都是在英文输入法和中文输入法之间进行切换，这样当我在Xcode、VSCode、Alred 等英文环境与 QQ、微信等中文环境进行切换时就非常的顺滑了

Image2icon - 制作你自己的文件图标

Monodraw - 绘制字符画

CheatSheet - 快速查看软件快捷键
