Swift 中的修饰器 @propertyWrapper

SSBun
2020-02-18 (Updated: 2020-02-18)
Property Wrapper, Swift

我们知道在 Python 中对属性方法都可以使用修饰器，修饰器能够监听、处理被修饰的属性或方法。这在处理一些普遍的逻辑时，能够让代码看起来更加的清晰和简洁，例如：获取用户信息前，需要用户先登录，而判断用户登录的逻辑，就无须写入获取用户信息的方法里，直接在外部使用修饰器就能够预先判断，并执行相应的逻辑，而在查看代码时，一眼就能看出这个方法需要让用户先登录。而实现这样的功能，必须依赖编译器的支持，现在 Swift5.1 提供了 @propertyWrapper 来实现部分修饰器的功能，如它的名字所示，它是一个对属性的包装。接下来我们来看一下这个 @propertyWrapper是如何使用的，在某些场景下，它能让我们的代码变的无比的简洁。
